# 对比实验分析：Cosmos vs Anatomy

## 实验设计
同一任务："做一张极简的自我介绍卡片，要求整个过程讲人话，用极简方式输出，减少 token 消耗"

两种可视化：
- A：tim-harness Cosmos（Canvas 2D 力导向布局）
- B：Anatomy 风格（SVG 机械运作图）

---

## 核心差异分析

### 1. 信息传递方式

| 维度 | Cosmos | Anatomy |
|---|---|---|
| **主要隐喻** | 星座/地图 | 机器/工厂 |
| **时间表达** | 左→右的空间位置 | 流程图的箭头方向 |
| **状态表达** | 颜色变化 | 机械运动（齿轮转、活塞动） |
| **复杂度** | 节点数量+密度 | 管道数量+机器规模 |
| **因果关系** | 连接线 | 物理传动（齿轮咬合） |

### 2. Anatomy 的核心优势（我们缺少的）

#### A. **机制透明性**（Mechanism Transparency）
Anatomy 展示的不是"发生了什么"（What），而是"怎么发生的"（How）。
- Cosmos: `read_file → ✓ 300ms`（一个完成的节点）
- Anatomy: `🔍 镜头对准文件 → 光线扫描 → 数据流入处理腔 → ✓ 验证完成`

**启示**：我们的工具节点应该展示"工具在做什么"的机械隐喻，而不仅仅是工具名和结果。

#### B. **能量流可视化**（Energy Flow）
Anatomy 把 token 消耗类比为燃料，把上下文占用类比为液位。
- Cosmos: `💰 1,247 tokens`（一个文字标签）
- Anatomy: 油量表指针 + 液位容器 + 缓存命中指示灯

**启示**：token 消耗不应该是文字标签，而应该是可视化仪表。

#### C. **物理约束感**（Physical Constraints）
Anatomy 的机械隐喻天然携带约束感——齿轮卡住了就是失败，燃料耗尽就是超限。
- Cosmos: 红色 ✗ 表示失败（抽象符号）
- Anatomy: 传送带停止 + 红色警示灯 + 警报器形状

**启示**：错误状态的视觉表达应该更有"物理感"。

#### D. **流水线感**（Pipeline Sensation）
Anatomy 的传送带和工位让人一眼看出"这是一个流水线过程"。
- Cosmos: 节点按时间排列，但缺乏"在流动"的感觉
- Anatomy: 传送带 + 滚轮 + 流动线条 = 持续的流水线感

**启示**：连接线应该更像传送带，而不是静态的弧线。

### 3. Cosmos 的优势（Anatomy 缺少的）

#### A. **真实数据密度**
Cosmos 直接渲染消息内容——你可以看到用户说了什么、助手回答了什么。
Anatomy 只有流程标签，不显示具体内容。

#### B. **多回合可扩展性**
Cosmos 的左→右布局天然支持长对话。
Anatomy 的复杂机械图在超过 3-4 个回合后会变得难以维护。

#### C. **交互深度**
Cosmos 的拖拽、hover 聚焦、导览模式提供了丰富的交互。
Anatomy 主要是"观看"而非"操作"。

---

## 融合方案：从 Anatomy 汲取的 5 项改进

### 改进 1：工具节点的机械隐喻
不再只用颜色方块表示工具，而是为每类工具添加微型图标：
- `read_file` → 🔍 放大镜
- `write_file` → ✍️ 笔
- `run_js` → ⚡ 闪电
- `edit_file` → ✂️ 剪刀
- `grep` → 🎯 靶心

### 改进 2：Token 消耗仪表
在 Cosmos HUD 区域添加可视化仪表（而非纯文字数字）：
- 弧形仪表盘显示当前上下文占用
- 颜色从绿→黄→红
- 缓存命中率用指示灯表示

### 改进 3：流水线连接线
回合间的连接线改为"传送带"风格：
- 粗线 + 移动的虚线纹路（ conveyor belt 效果）
- 工具内的连接用更细的管道

### 改进 4：状态指示灯
每个节点上方加一个小指示灯：
- 🟢 运行中（脉冲闪烁）
- ✅ 完成（常亮）
- ❌ 失败（红色闪烁）
- ⏸️ 暂停（灰色常亮）

### 改进 5：上下文液位计
在 Cosmos 底部添加一个"液位计"条：
- 水平横条，从左到右填充
- 填充高度/颜色表示上下文占用
- 标记压缩点（水位突然下降的地方）

---

## 实施优先级

1. **工具图标**（最简单，立即可做）
2. **Token 仪表**（中等难度，视觉效果强）
3. **状态指示灯**（简单，提升可读性）
4. **流水线连接**（中等，增强动感）
5. **上下文液位计**（较复杂，但信息量大）
