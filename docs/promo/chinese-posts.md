
### 正文
---

做了一个完全在浏览器里运行的大模型编程智能体。

**核心特点：**
- 打开网页就能用，不需要部署任何服务
- 19 个工具：文件读写、JS 沙箱、网页搜索、子代理、快照
- Token 五层优化，DeepSeek 实测省 84-90% 输入费用
- 4 种可视化模式（包括把工具调用变成红警暴兵的战场模式）

**技术栈：** TypeScript + React + Three.js，纯前端，六边形架构。

在线试用：https://hongxin.github.io/tim-harness/
源码：https://github.com/hongxin/tim-harness

支持 DeepSeek / OpenAI / Gemini（免费层）/ 智谱 GLM / Ollama 本地模型。
