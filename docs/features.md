# 完整功能列表

本文档包含 Tim Harness 的全部功能详情。README 中只展示核心亮点。

## 智能体核心

| 能力 | 说明 |
|---|---|
| 多轮工具调用 | 18 个工具，完整 agent loop |
| 流式渲染 | 内容/思考链/工具调用全程流式 |
| 目标驱动 🎯 | 自动连续推进，模型自报 complete/blocked |
| 子代理 | `spawn_agent` 派生独立上下文的子任务 |
| 任务清单 | `todo_write` 维护计划，面板实时投影 |
| 技能系统 | `/skills/<名称>/SKILL.md` 自动索引 |
| 工具审批 | 可选开启，写操作需人工批准 |

## Token 经济（五层防线）

| 层级 | 机制 | 效果 |
|---|---|---|
| 1. 工具输出瘦身 | offset/limit 分页、自动截断 | 减少单次输出 |
| 2. 前缀缓存 | 双通道提示词（稳定段+易变段） | DeepSeek 命中价 1/50 |
| 3. 视图折叠 | 旧工具结果折叠 | 减少上下文占用 |
| 4. 增量压缩 | LLM 总结早期消息 | 长会话不爆窗 |
| 5. 成本档位 | eco/standard/full 一键切换 | 全场景覆盖 |
