# taste-skill 思想方法提炼（对 tim-harness 的审美改良指导）

> 来源：[Leonxlnx/taste-skill](https://agenticskills.io/skills/taste-skill)（529 行 SKILL.md，
> 基于 247 个获奖网站的研究，含统计支撑）。本文提炼其核心思想并映射到 tim-harness 的改良。

---

## 一、核心理念（一句话）

**"一个由模型生成的页面看起来像它见过的每个页面的平均值——没有什么是错的，但也没有什么是被'决定'的。"**

→ **用"决策"取代"默认"**。每个视觉元素应该是被选择的结果，而不是 AI 的统计均值。

---

## 二、对 tim-harness 的直接改良映射

### 1. 反 AI 模板化（Anti-Slop）—— 去除生成感

taste-skill 的统计数据（247 站研究）：

| 特征 | 高分站（≥7.5分） | 低分站（<6.5分） | tim-harness 现状 |
|---|---|---|---|
| 图标特征卡 | 1% | 28% | ❌ 空态示例卡片有此倾向 |
| 渐变 | 22% | 52% | ✅ 已用纯色 |
| 阴影/发光 | 24% | 48% | ⚠️ 有 shadow 使用 |
| 小型大写字距标签 | 16% | 57% | ❌ `.as-micro` 等存在 |
| 药丸徽章 | 14% | 34% | ⚠️ `.rp-count` 等 |

**行动项**：
- [ ] 空态示例卡改为非均质布局（当前三卡等宽等距 = 模板感）
- [ ] 去除多余 shadow（仅浮层保留：菜单、弹窗、悬浮按钮）
- [ ] 微标签改为句首大写可读尺寸

### 2. 主题决定风格（Idea from Subject）

**"最好的站点的概念来自事物本身，而非样式"**

tim-harness 的"主题"是什么？→ **终端/工程/控制台**。不是通用聊天 App。

**行动项**：
- [ ] 空态不再使用"通用 AI 助手"的欢迎文案+三卡片，改为终端风格的启动序列（有仪式感）
- [ ] 品牌区从"TIM HARNESS + 副标题"改为一个有辨识度的视觉锚（如：一个 ASCII art logo 或终端光标闪烁）
- [ ] 主题色应来自"终端文化"的固有色彩（磷光绿/琥珀/IBM 蓝），而非通用蓝紫

### 3. 一个想法（One Idea）+ 一个活物（One Live Thing）

**"每一屏的获胜页面都有一件访客可以做的事，评委首先叫出它的名字"**

tim-harness 的"活物"候选：
- **空态**：输入区有一个闪烁光标 + 一行提示 = 终端的"活着"感
- **Cosmos**：气泡的诞生脉冲和呼吸 = 会话的"活着"感
- **流式输出**：光标动画 + 逐字渲染 = 模型的"思考中"

**行动项**：
- [ ] 空态加一个终端式启动序列（`> system ready` + 光标闪烁），而非三张卡
- [ ] 保持 Cosmos 的诞生脉冲（已有 ✓），确保不被移除

### 4. 文字直接可见（Content on the Surface）

**"气泡上直接渲染内容文字——这是核心直观性来源"**

这与 JetBot Cosmos 的教训完全一致。应用到 tim-harness：
- 工具卡片：成功时折叠但显示关键参数（不是空白折叠条）
- 侧栏文件树：文件名即内容（已有 ✓）

### 5. 排版法则（Type Laws）

taste-skill 的排版数据：
- 大标题/正文比中位数 **4.3:1**（最佳站远超此比）
- 标题字距 **-0.02 到 -0.05em**（收紧），行高 0.85-1.05（紧凑）
- **两三个字号做全部工作**：一个很大，一个小，中间不要
- 五个字号是一个页面的上限
- **左对齐为默认**；最多居中一个时刻

**行动项**：
- [ ] 主页标题（空态 h1）加大至少 2 倍（当前 24px 太小，应 48-64px）
- [ ] 全局收紧字距（标题类加 `letter-spacing: -0.02em`）
- [ ] 减少中间字号层级（目前 12/12.5/13/13.5/14 太密集）

### 6. 色彩法则（Color Laws）

- **一个底色、一个墨色、一个强调色**。强调色出现在按钮上，最多还有一个地方。
- **正文用全墨色**。灰色只用于次要注释。一个用浅灰排版的页面读起来未完成。
- **表面用色调差异分隔**，永远不用线或阴影。

**行动项**：
- [ ] 检查正文颜色：`--text-dim`（#8b95a5）用于太多正文 → 提高到接近 `--text`
- [ ] 工具卡/面板的分隔：用背景色阶差（已有 ✓ `--bg-panel` vs `--bg`），去除多余 border
- [ ] 强调色（绿色 #4ade80）只用在：发送按钮、在线状态、成功指示——不要到处都是

### 7. 无装饰规则（House Rules）

直接适用于 tim-harness 的禁令：

| 规则 | tim-harness 检查 |
|---|---|
| 无细线 | ⚠️ `border: 1px solid` 大量使用 → 改为背景色阶差 |
| 无渐变 | ✅ 纯色为主 |
| 无发光 | ⚠️ Cosmos 有 glow → 保留（功能性的，表示"活着"） |
| 无图标置顶特征卡 | ❌ 空态示例卡需要改 |
| 无等距卡片行 | ❌ 空态三卡等距 → 改为不等距或列表式 |
| 无小型大写标签 | ⚠️ `.as-micro` / `.fs-badge` → 改为句首大写 |
| 无玻璃效果 | ✅ |
| 无装饰形状 | ✅ |

### 8. 图像法则（Imagery）

- **一张主图胜过六张小图**
- **无图好过占位符、图标或抽象形状**
- **为此主题画的图（用它的色彩、用心理画）好过两者**
- **找到的真实世界的图（有出处）好过一切**

**行动项**：
- [ ] 空态不放图标/装饰，放一个大的视觉锚（终端光标/ASCII 图/大字标题）

---

## 三、优先改良清单（按影响力排序）

1. **空态重做**——从"通用 AI 欢迎页"改为"终端启动序列"（有主题、有想法、有活物）
2. **排版比例**——标题/正文比拉大，字号层级减到 3 级
3. **正文颜色**——从灰调提升到接近全墨
4. **去线条化**——border 改为背景色阶差
5. **去模板化**——空态三卡改为非均质布局
